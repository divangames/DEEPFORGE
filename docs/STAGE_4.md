# Stage 4 — Full Mine

Stage 4 превращает вертикальный срез из трёх уровней в полноценную шахту из 30 добывающих Deck.

## Что реализовано

- 30 добывающих уровней (`Deck 01` … `Deck 30`).
- Сохранение совместимо со Stage 1–3: старые Deck 01–03 остаются открытыми и сохраняют уровни/буферы/менеджеров.
- Вертикальная прокрутка шахты колесом мыши и drag/swipe на телефоне и планшете.
- Пять барьеров после Deck 05 / 10 / 15 / 20 / 25.
- Барьер требует открытия последнего Deck текущей секции, денег и времени на расчистку.
- Таймер барьера продолжает идти, когда игра закрыта.
- Новые Deck открываются последовательно и имеют возрастающую стоимость.
- Regular Managers автоматически создаются для каждого открытого Deck; первые три сохраняют именные профили Stage 2.
- Bulk upgrades: `×1`, `×10`, `×25`, `MAX`.
- Стоимость bulk-покупки считается геометрической формулой, а не тысячами последовательных циклов.
- Milestones уровней: 10 / 25 / 50 / 100 / 200 / 500 с крупными производственными множителями.
- Bottleneck HUD показывает throughput добычи, Lift и Logistics и подсвечивает реальное узкое место.
- UI панели объекта умеет отображать закрытый/недоступный Deck.
- Вкладка «Команда» расширяется автоматически по мере открытия уровней.

## Порядок прогрессии

1. Stage 1–3 save начинает с Deck 01–03.
2. Deck 04 и 05 можно купить по очереди.
3. После Deck 05 становится доступна расчистка первого барьера.
4. После таймера открывается доступ к Deck 06–10.
5. Цикл повторяется до Deck 30.

## Bottleneck

Для интерфейса рассчитывается потенциальный throughput:

- `Shafts = Σ yield / cycle`
- `Lift = capacity / cycle`
- `Hub = capacity / cycle`
- `Effective = MIN(Shafts, Lift, Hub)`

Самое маленькое значение подсвечивается как узкое место.

## Mobile-first

- Вся шахта прокручивается вертикальным свайпом.
- Основные действия остаются в React dock и имеют touch-area не меньше 44 px.
- На сцене используются крупные интерактивные кнопки.
- Никакая новая механика не требует hover, клавиатуры или правого клика.
