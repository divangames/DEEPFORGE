# Этап 0 — Foundation

## Цель

Создать устойчивый фундамент, на который будут последовательно добавляться игровые системы.

## Архитектурное решение

### Canvas / Phaser

Отвечает за игровую симуляцию и визуальные сущности:

- рабочие;
- добыча;
- Lift;
- транспорт;
- частицы;
- карта;
- анимации.

### React

Отвечает за интерфейс:

- HUD;
- меню;
- модальные окна;
- Specialists;
- Research;
- leaderboard;
- магазин.

### IndexedDB

Локальное сохранение и offline-first слой.

### Backend

Серверная истина для будущих:

- аккаунтов;
- cloud save;
- leaderboard;
- событий;
- server time;
- anti-cheat.

## Mobile-first правила

- базовая ширина проектирования: 360 px;
- кнопки не меньше 48 px по высоте;
- важные действия не требуют hover;
- safe-area учитывается;
- на ПК боковая навигация, на телефоне нижняя;
- Phaser использует Resize Scale Mode.

## Почему Phaser 4

Проект стартует в 2026 году с нуля, поэтому foundation использует актуальную стабильную ветку Phaser 4 вместо старой Phaser 3. Игровые системы остаются отделены от движкового слоя, чтобы обновления движка не ломали экономику.

## Definition of Done

- `npm run typecheck` проходит;
- `npm test` проходит;
- `npm run build` проходит;
- API health endpoint запускается;
- клиент не падает без PostgreSQL;
- макет адаптируется к телефону / планшету / ПК;
- PWA генерируется production build.
