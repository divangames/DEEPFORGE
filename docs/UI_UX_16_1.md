# UI/UX 16.1 — исправления перед Reactor Grid

## Задача

Привести накопившиеся экраны к одной mobile-first системе. Приоритет — вертикальный телефон, включая контрольный размер 430×932 и уменьшенную доступную высоту Safari. Механики Stage 16 сохранены; Reactor Grid в это обновление не входит.

## Аудит и изменения

| До | После | Почему |
| --- | --- | --- |
| 2708 строк накопленных CSS-патчей; отдельные панели переопределяют размеры друг друга | Единые токены и один адаптив; Rift использует общую оболочку | Следующий экран не требует нового слоя взаимоисключающих правил |
| Подписи 6–9px в мобильных правилах, перегруженные карточки | Текст 13–16px, вторичные подписи 11–12px; DOM-кнопки не менее 44px | Вместо уменьшения всего скрываются дополнительные подробности |
| Доход, служебный HUD и события поверх Canvas | Производственная цепочка вынесена в выделенную полосу; события в нижней навигации | Шахту не перекрывают плавающие баннеры |
| Dock растёт вместе с описанием менеджера | По умолчанию объект, краткие характеристики, bulk и покупка; подробности раскрываются | Основные действия всегда рядом; у деталей свой scroll |
| Несколько независимых `open` boolean | Один типизированный `PanelState` | Нельзя случайно сложить карту, команду и Rift друг на друга |
| Разные div-overlay и частично нативные окна | Общий `Dialog` с top-layer, Escape, циклом Tab и возвратом фокуса | Одинаковое предсказуемое поведение; фон не получает фокус |
| Вкладки — просто ряд кнопок | Общий `Tabs`: aria-selected, roving tabindex, Arrow/Home/End | Доступность не требует мыши, порядок фокуса понятен |
| Менеджеры/Research/Meta/события используют разные типографику и карточки | Общие поверхности, отступы, кнопки и ограничения высоты | Игра воспринимается как один интерфейс |
| `100vh`/dvh и safe-area разнесены между панелями | Одна `--app-height`, safe-area один раз на край, visualViewport для клавиатуры | Панели не должны уходить под браузерные элементы |
| Одни и те же hover-правила на мыши и touch | Hover только при hover+fine pointer, короткий :active feedback | Нет «залипшего» увеличения после тапа |
| Мелкий текст поля и общий запрет выделения | Поля 16px, контент можно выделить, zoom не запрещён | Не нужен опасный `maximum-scale=1` |
| Непроверенная строка ID, копирование могло сообщать успех при ошибке | Проверка формата/своего ID/дублей/лимита; сообщение об ошибке Clipboard | Действие и обратная связь соответствуют результату |
| Сбросы через немедленное действие/системный confirm | Подтверждение внутри Research/Rebuild/Rift/Blitz с описанием потерь | Ясно, что произойдёт, до необратимого действия |
| Точки карты пересекались с легендой | У маршрута своя область; точки 44–48px, названия выбранного объекта ниже | Карта читается и не требует попадания в крошечную подпись |
| Phaser реагировал преимущественно на resize окна | ResizeObserver контейнера + scale.refresh; Canvas memo | Раскрытие Dock и Safari меняют сцену корректно |
| Каждый новый modal сам решал, останавливать ли визуальные обновления | Общий Dialog использует coverGameScene | Экономика продолжается, скрытая сцена делает меньше визуальной работы |
| Blitz setInterval мог перекрывать запросы | Последовательный опрос; скрытая вкладка пропускается; нажатие не теряется из-за текущего чтения | Меньше лишнего сетевого трафика и гонок чтения |
| Тап по маленькому названию уровня | Выбирается вся карточка уровня; запуск/барьер увеличены; multi-touch не перехватывает текущий свайп | Проще управление пальцем без изменения экономики |

## Новая навигация

**Шахта → Карта → Команда → Наука → События.**

Rebuild доступен через подробности текущего объекта и экран информации. «Команда» содержит менеджеров, специалистов, Академию, друзей и Meta. События открывают Weekly, Season, Blitz и Rift. Окно «Пока вас не было» не вклинивается поверх другого открытого экрана и объясняет, что начисление уже сохранено.

## Компоненты и правила

- `client/src/ui/components/Dialog.tsx`, `Tabs.tsx`, `Icon.tsx`.
- `client/src/ui/platform/dialogController.ts`, `viewport.ts`, `uiState.ts`.
- `.agents/skills/deepforge-ui/SKILL.md`, `.cursor/rules/deepforge-ui.mdc`.
- `scripts/test-ui-policy.cjs`, `scripts/render-ui-fixtures.cjs`, `qa/uiux/`.

Новых runtime-зависимостей, сторонних шрифтов и графических пакетов нет. Анимации счётчиков/покупок/выбора уровня не добавлены; press feedback отключается при reduced-motion. Финальная графика шахт по-прежнему отдельный этап.

## Сохранность проекта

Schema v12, ID объектов и данные инвентаря не менялись. В экономических core-модулях, миграциях, API и SQL-схемах изменений нет. В FoundationScene изменены только визуальные подписи, hit area, обработка свайпа и позиционирование камеры. `publish.bat` и `.github/workflows/pages.yml` совпадают с базовым Stage 16 по байтам.
