## Точный характер браузерных проверок

Генератор `scripts/render-ui-fixtures.cjs` исполняет исходный JSX с фиксированными view-данными и создаёт статический HTML. **React effects, реальный React runtime, Phaser Canvas, IndexedDB и HTTP в этих фикстурах не запускаются.** Это проверка структуры/размеров/скролла, а не E2E всей игры. Вместо Canvas в макетах явно подписана область игровой сцены.

`qa/uiux/platform.py` отдельно выполняет реальный код новых platform helpers в Chromium с нативным `HTMLDialogElement`. Проверяется фокус и обработка клавиатуры, а также resize visualViewport. Проверка zoom-guard использует контролируемый scale=2. Физическая экранная клавиатура iOS этим не проверяется.

Среда: Node.js 22.16.0, установленный TypeScript 5.8.x для независимых проверок, Chromium / Python Playwright. Версия TypeScript в проекте и версии остальных зависимостей не менялись.

Машинные результаты: `UI_UX_16_1_RESULTS.json`.

## Что НЕ подтверждено

1. Полный `npm install → typecheck → vitest → production build` в этой среде не выполнен. `npm ping` завершился `EAI_AGAIN / getaddrinfo registry.npmjs.org`. Проверки через искусственные React-типы не выдаются за полный typecheck.
2. Физический iPhone/Safari/PWA и iOS-клавиатура не проверялись. Проверка 430×932 в Chromium не равна испытанию iPhone 14 Pro Max.
3. FPS/расход батареи на реальных слабых телефонах не замерены. В коде сокращена работа закрытой сцены и добавлено корректное обновление Canvas, но численного прироста производительности не заявляется.
4. Реальный `ResizeObserver → Phaser.scale.refresh` требует проверки в собранной игре с установленным Phaser. Неподдерживаемые свойства GameConfig не добавлялись.
5. Запросы к живому VPS и production-базе не проверялись. Сетевые режимы по-прежнему требуют backend.

## Перед публикацией

`publish.bat` обязан успешно закончить typecheck, тесты и build **до** push. В `npm test` включены новые UI-policy проверки. Скрипт публикации и workflow не изменялись.

После deployment на реальном iPhone проверить: вертикальную шахту с раскрытым/закрытым Dock, выбор нижнего уровня, скролл карты, последнюю карточку команды, ввод ID с открытой клавиатурой, Escape/Tab на ПК, возврат из события. Проверить обычный Safari и установленную PWA. Не очищать данные сайта ради обновления — там сохранения.

Если фактический экран отличается от макета, приоритет у устройства пользователя. Следующая игровая механика не должна маскировать UI-регрессию.
