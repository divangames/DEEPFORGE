# Проверки патча Git / TypeScript 16.1

Среда выполнения: Linux, Node.js 22.16.0, Git 2.47.3.
Дата: 30 сентября 2026 г.

## Выполнено

### 32 интеграционных теста publisher — пройдены

Запуск: `node --test scripts/deepforge-publish.test.cjs`.
Использованы настоящие временные Git-репозитории и локальный bare remote.
Репозиторий пользователя в этих тестах не изменялся.

Проверено сохранение новых и изменённых исходников, восстановление независимой
истории через новый clone и два согласия, отказ на каждом этапе, сохранение
старой папки/истории, сохранение remote-only файлов, отсутствие переноса .env,
неизменность GitHub при провале проверки, защита от публикации другой игры,
попытки повторного запуска в старой папке, изменения во время проверки,
символические ссылки, неглубокая история и реальные конфликты.

Один тест запускает настоящую цепочку npm install → typecheck → test → build
на минимальном проекте без внешних зависимостей. Это тест механизма publisher,
НЕ полная сборка DEEPFORGE.

### 10 тестов запуска локального TypeScript CLI — пройдены

Запуск: `node --test scripts/local-typescript.test.cjs`.

Смоделирован пакет, у которого exports запрещает `typescript/bin/tsc`
и `typescript/package.json`, но поле bin объявляет публичный launcher.
Старый require.resolve действительно выдаёт ERR_PACKAGE_PATH_NOT_EXPORTED,
новый resolver находит и запускает CLI. Проверены пути с кириллицей, пробелами
и !!!, workspace/hoisting, Node shebang, ошибка компилятора и отсутствие
неявной установки/глобального fallback. Выбор native binary проверен на
сигнатуре fixture; это НЕ запуск Windows .exe в Linux.

### 19 реальных тестов ядра Rift — пройдены

Запуск `npm run test:rift` в копии исходного DEEPFORGE UI/UX 16.1.
Компилировались настоящие protocol/engine/repository/service/validation.
Для этого изолированного запуска локально подключён установленный в среде
TypeScript 5.8.3 и доступные определения @types/node. Версии исходного
package.json не менялись, эти зависимости в ZIP не включены.

### 10 реальных UI-policy проверок — пройдены

Запуск `npm run test:ui-policy` в той же копии проекта с TypeScript 5.8.3.
Проверены переключение панели, закрытие, reference count скрытия сцены,
валидация своего/повторного/неправильного Player ID и лимита друзей.
Браузерный рендер и React-взаимодействия этим тестом не покрываются.

### Упаковка

- `publish.bat`: ASCII, без BOM, CRLF, DisableDelayedExpansion.
- Node.js-скрипты прошли `node --check`.
- В ZIP нет .git, node_modules, .env, dist или зависимости от папок среды.
- Изменения ограничены инструментами публикации/проверки и документацией.

## Ограничения

- TypeScript 7.0.2 из package.json не установлен в этой среде: DNS-доступ к
  registry.npmjs.org отсутствует. Полная сборка React/Phaser/Fastify не проверена.
- Воспроизведён механизм ошибки exports, но это не равнозначно полной
  компиляции проекта всеми версиями TypeScript.
- Нативный CMD/Windows, Git Credential Manager, браузерная авторизация
  и реальный push в GitHub в этих тестах не выполнялись.
- npm test/typecheck/build остаются обязательными у пользователя перед push.
