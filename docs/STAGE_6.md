# Stage 6 — Multi-Sector Economy

## Цель

Перевести Stage 5 с одной картой Rust Valley на полноценную мировую структуру из нескольких регионов, не ломая уже созданную 30-level шахту и мобильный интерфейс.

## Реализовано

- 8 секторов мира.
- 5 добывающих объектов в каждом секторе — всего 40 конфигураций.
- Отдельная валюта каждого сектора.
- Общий кошелёк для всех пяти шахт одного сектора.
- Последовательное открытие секторов.
- Для открытия нового сектора требуется открыть все 5 объектов предыдущего и выполнить lifetime-условие.
- Первый объект нового сектора открывается автоматически вместе с сектором.
- Двухуровневая карта:
  - World Atlas — 8 секторов;
  - Sector Map — 5 объектов выбранного региона.
- Независимые карты, ресурсы, цвета и экономические коэффициенты регионов.
- Background income всех автоматизированных шахт продолжает работать.
- Offline income начисляется в правильную валюту каждого сектора.
- Offline summary показывает награды отдельно по секторам.
- Save schema v4.
- Миграция Stage 5: отдельные кассы Rust Valley суммируются в общий `Rust Credits` wallet без потери денег.

## Сектора

1. Rust Valley — `RC / Rust Credits`
2. Glacier Belt — `CC / Cryo Credits`
3. Ember Fault — `ES / Ember Scrip`
4. Aurora Steppe — `AM / Aurora Marks`
5. Twilight Basin — `DT / Dusk Tokens`
6. Relic Wastes — `RB / Relic Bonds`
7. Sunken Shelf — `AC / Abyss Credits`
8. Storm Cradle — `SM / Storm Marks`

## Save

Деньги больше не являются частью экономики конкретной шахты. Поле `PersistentMineState.cash` оставлено только для обратной совместимости, но при сохранении Stage 6 записывается как `0`.

Актуальные деньги находятся в:

```ts
world.sectorWallets[sectorId]
```

Это позволяет нескольким автоматизированным шахтам одного региона одновременно пополнять общий баланс.

## Проверки

- 8 уникальных секторов.
- 40 уникальных Mine ID.
- 5 объектов в каждом секторе.
- разные валюты регионов.
- Stage 3/4 legacy save → Rust Valley wallet.
- Stage 5 multi-mine save → сумма касс Rust Valley без потери денег.
- `MineSimulation.setCash/getCash` для синхронизации общего кошелька.
- TypeScript проверка изменённых модулей и всего client source через локальные type stubs.
