# DEEPFORGE — обязательные правила интерфейса

Работаем по принципам Emil Kowalski: ясная иерархия, мгновенное понятное действие, отсутствие лишнего движения. Этот файл — **проектный профиль**, а не копия или установка всей upstream-библиотеки.

## Основа

Вертикальный телефон — первая платформа. Проверять минимум 360×640 и 430×932, затем уменьшенную высоту Safari, планшет и ПК. Не угадывать устройство через User-Agent. Реальный iPhone проверяется отдельно от эмуляции.

Использовать токены `client/src/ui/styles.css`, общие `Dialog`, `Tabs`, `Icon`. Не добавлять очередной изолированный CSS-патч с конфликтующим `100vh`, собственным z-index и шрифтами 6–9px. Текст содержания 13–16px, вторичные подписи 11–12px, области кнопок от 44px. Если места мало — скрыть дополнительные подробности за явным раскрытием, а не уменьшать всё.

В приложении одновременно одно модальное окно. Вход в режимы — через «События», не через ещё один плавающий баннер над шахтой. При закрытии вернуть фокус к навигации; Escape закрывает, Tab не уходит на фон. Для `Tabs` нужны aria-selected, roving tabindex, стрелки/Home/End и связанный tabpanel.

Safe-area учитывается один раз на каждом краю. Высота оболочки — `--app-height`, внутренние области имеют `min-height:0`, `overflow:auto`, `overscroll-behavior:contain`. Для клавиатуры используется `visualViewport` без вмешательства в pinch zoom. Не добавлять `maximum-scale=1` или `user-scalable=no`. Поля ввода минимум 16px. Не блокировать выделение текста на body.

Hover-эффекты только внутри `@media (hover:hover) and (pointer:fine)`. Кнопки дают короткую обратную связь через `:active`, не через ожидание ответа сервера. Частые действия и цифровые счётчики не анимировать. Не добавлять `transition:all`, blur-фильтры на всю сцену и бесконечные декоративные циклы. Учитывать prefers-reduced-motion.

Ошибки и пустые состояния должны говорить, что произошло и какое действие доступно. Копирование успешно только после успешного Clipboard API. Деструктивные сбросы подтверждаются в интерфейсе с явным описанием потерь. Недоступный backend не маскировать выдуманным рейтингом.

## Производительность и проверки

Не создавать Phaser-сцену для каждого окна. Общий Dialog сообщает о закрытой сцене через `coverGameScene`; экономика работает дальше, визуальная работа уменьшается. Canvas получает ResizeObserver + scale.refresh. Не возвращать неподдерживаемый `GameConfig.resolution`.

До сдачи: настоящий typecheck + тесты + build, когда доступны зависимости. При ограничениях честно разделять статические JSX-фикстуры, DOM-тесты, pure core тесты, запуск React и физическое устройство. Не писать «проверено на iPhone», когда менялся только viewport в Chromium.

Сохранения, баланс, publish.bat, workflow, .git и .env не менять ради визуального прохода. Следующий этап механик начинается после устранения текущих UI-регрессий.
