# DEEPFORGE: Idle Empire — Stage 16

Браузерная idle-игра. Основной экран — вертикальный телефон; также планшеты и ПК.

## Rift Expedition

Пять последовательных объектов, собственные Rift Credits / RP, три автоматизированных производственных звена, шесть технологий, десять наград и серверный рейтинг. Вход: **События → Rift Expedition**. Меню «События» заменяет стопку баннеров Weekly / Season / Blitz; старые режимы доступны там же.

Исходная база: опубликованный Stage 15, commit `7f6f2b31133d61857ba9ebd3ba89643fe78d5d59`. Stage 16 предоставляется как исходники; сам архив не публикует сервер и не меняет настройки GitHub.

## Установка поверх проекта

Скопируйте **содержимое** папки `deepforge-stage-16` из архива в свою существующую рабочую папку рядом с `.git`, `client`, `server` и `package.json`, с заменой файлов. Не создавайте вложенный проект.

В архиве нет `.git`, `node_modules`, `dist`, секретов и `package-lock.json`. Ваш существующий lockfile остаётся на месте. Версии зависимостей не менялись. Исправленный `publish.bat` сохранён; workflow Pages не изменён.

```bat
publish.bat "feat: stage 16 rift expedition"
```

Батник выполняет синхронизацию, проверку типов, тесты и сборку до commit/push. В тесты включены проверки Rift. Принятый push не означает, что Pages уже обновился: проверьте результат GitHub Actions.

## Проверка Rift без VPS и базы

Остановите ранее запущенные dev-серверы на портах 5173 / 3001 и запустите:

```bat
dev_rift_memory.bat
```

Откройте `http://localhost:5173`, затем **События → Rift Expedition → Подключить гостевой профиль → Начать экспедицию**. Настройки применяются только к окну запуска; `.env` не перезаписывается.

**DEV MEMORY:** серверные профили, очки и награды исчезают после остановки процесса. Это локальный тестовый режим. Обычное локальное сохранение шахт не удаляется. После перезапуска MEMORY старый гостевой ключ перестаёт работать; UI предлагает явно создать новый профиль.

## Pages и сервер

На GitHub Pages без API доступен обзор Rift с надписью `SERVER REQUIRED`. Для сетевой игры нужен отдельно запущенный backend Stage 16 с PostgreSQL. Переменная сборки клиента `VITE_API_URL` должна содержать HTTPS-адрес API без завершающего `/api`. Обновление только Pages не обновляет VPS.

Гостевой профиль Rift пока отдельный от локального Player ID / Blitz. Награды записываются в **серверный запас Rift**; перенос в локальные шахты ещё не подключён. RP тратятся внутри экспедиции уже сейчас.
